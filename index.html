02 · Proses

Cara kerja

Semua konversi terjadi di perangkatmu sendiri lewat opentype.js — SVG tidak pernah dikirim ke server mana pun.

01

Vector per karakter

Tiap huruf, angka, dan simbol adalah file SVG terpisah — hasil tracing tulisan tangan atau desain vector manual.

02

Fit otomatis

Setiap glyph diskalakan ke bounding box yang sama, sejajar pada baseline dan cap-height, supaya rapi saat diketik berdampingan.

03

Rakit jadi .ttf

Glyph disusun jadi tabel font TrueType lengkap dengan metrik advance width, lalu diunduh langsung sebagai file .ttf.
